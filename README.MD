#Catch It All
Catch Every Thought. Crush Every Task.

Catch It All is a sleek, full-stack web application built with the MERN stack (MongoDB, Express.js, React.js, Node.js). Engineered with JWT (JSON Web Tokens) and bcrypt for robust data security and authentication, Catch It All reimagines task management and note-taking into one seamless, distraction-free platform.

Featuring a modern dark-mode UI, real-time filtering, customizable categories, and built-in productivity widgets, Catch It All is designed to keep your chaos organized and your workflow fast.

✨ Features
🔒 Secure Authentication: JWT-based sessions with password hashing via bcrypt.

📝 Notes & To-Do Lists: Dynamic creation, editing, and organization for all your ideas and daily targets.

🎨 Color & Category Filtering: Easily filter and sort your workspace by type or custom colors.

🌙 Sleek Dark UI: Modern, eye-friendly aesthetic designed for late-night lightbulb moments.

⏱️ Integrated Tools: Built-in live clock and widget utilities to stay on track.

🛠️ Tech Stack
Frontend: React.js, MDB React UI Kit, React Router, CSS3

Backend: Node.js, Express.js

Database: MongoDB

Security: JSON Web Tokens (JWT), bcrypt
